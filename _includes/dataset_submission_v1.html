Submit a pull request to the FluidsBench submission repository. Each result is one directory at submissions/{{ include.slug }}/<submission-id>/ containing:

  • submission.json for model metadata and the required scalar metrics;
  • evaluation-evidence.json linking those metrics to the recorded evaluation revision and profile-index checksum;
  • profiles/index.json listing the lightweight profile chunks; and
  • profiles/chunk-*.json containing profile coordinates and predictions for the declared test cases.

Contributors calculate the metrics and extract the profiles from their own predictions. No surface meshes or volume fields are submitted. Use the {{ include.dataset }} benchmark specification for the exact split, metric, case, panel, station, and quantity IDs. The reference equations and code define how the scalar values must be calculated, and the worked examples show the JSON structure.

Before opening a pull request, run python scripts/validate_submission.py submissions/{{ include.slug }}/<submission-id>. The validator checks the schema, split identity, derived-score arithmetic, profile coverage, array lengths, ordering, finite values, and chunk hashes. It checks the submitted package's internal consistency; it does not run the contributor's model or independently recalculate base metrics from full fields.

Prototype notice: current test case IDs and profile values are illustrative until each dataset owner replaces the generated split files with the official benchmark case lists.
