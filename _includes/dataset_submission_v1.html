Submissions are currently closed. When they open, contributors will propose one result directory at submissions/{{ include.slug }}/<submission-id>/ in the FluidsBench submission repository. The planned result package contains:

  • submission.json for model metadata and the required scalar metrics;
  • evaluation-evidence.json linking those metrics to the recorded evaluation revision and profile-index checksum;
  • profiles/index.json listing the lightweight profile chunks; and
  • profiles/chunk-*.json containing profile coordinates and predictions for the declared test cases.

FluidsBench uses an open reproducibility track. The declared evaluation partition, scored case lists, and ground truth are public. Evaluation cases must not be used for fitting, hyperparameter selection, or preprocessing statistics. Contributors will calculate the metrics and extract the profiles from their own predictions. No surface meshes or volume fields are submitted. Use the {{ include.dataset }} benchmark specification for the exact split, metric, case, panel, station, and quantity IDs. The reference equations and code define how the scalar values must be calculated, and the worked examples show the JSON structure.

Before opening a pull request, run python scripts/validate_submission.py submissions/{{ include.slug }}/<submission-id>. The validator checks the schema, split identity, derived-score arithmetic, profile coverage, array lengths, ordering, finite values, and chunk hashes. It checks the submitted package's internal consistency; it does not run the contributor's model or independently recalculate base metrics from full fields.

A passing validator or pull request will not make a result official. Official results will require openly accessible evaluation code pinned to an immutable revision, an openly accessible versioned model artifact with a cryptographic digest and licence, a locked environment and replay instructions, and an independent maintainer replay that reproduces the submitted metrics within published tolerances. FluidsBench will publish the replay evidence with the result.

Prototype notice: current case IDs, ground truth, profile values, and leaderboard rows are illustrative dummy data. Dataset owners must replace and approve these materials before submissions open; none of the current rows is an official or replay-verified result.
