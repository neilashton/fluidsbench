BlendedNet dataset

Dataset overview and leaderboard submission format for BlendedNet.

Overview

BlendedNet is a high-fidelity aerodynamic dataset for parametrically generated blended-wing-body aircraft. The published training and validation pool contains 8,830 cases from 999 geometries. A separate test release contains 870 cases from 100 geometries that do not occur in the training pool.

The cases use steady RANS simulations in FUN3D with the Spalart-Allmaras turbulence model and meshes of roughly 9-14 million volume cells. Inputs combine surface coordinates and normals, nine geometry parameters, altitude, Reynolds number, Mach number, angle of attack, and sideslip angle.

The initial FluidsBench target follows the published surrogate: surface Cp, Cfx, and Cfz, plus integrated CD, CL, and CMy. The archive also contains Cfy, but it is not ranked until a dataset-owner-approved evaluator adds it to the benchmark contract.

Planned benchmark split

Set the submission split to the exact ID below. Cases are grouped by geometry, and the fixed test geometries must not be used for model fitting, hyperparameter selection, or preprocessing statistics.

Split ID Train/validation pool Fixed test
geometry_holdout 8,830 cases from 999 geometries 870 cases from 100 unseen geometries

The publication divides the 8,830-case pool into 90% training and 10% validation by geometry. FluidsBench records the released pool as one split because submissions are evaluated against the separate geometry-disjoint test set.

Planned open-reproducibility submission

Submissions are currently closed. When they open, contributors will propose one result directory at submissions/blendednet/<submission-id>/ in the FluidsBench submission repository. The planned result package contains:

  • submission.json for model metadata and the required scalar metrics;
  • evaluation-evidence.json linking those submitter-provided metrics to the declared evaluation revision and profile-index checksum;
  • profiles/index.json listing the lightweight profile chunks; and
  • profiles/chunk-*.json containing profile coordinates and predictions for the declared test cases.

FluidsBench uses an open reproducibility track. The declared evaluation partition, scored case lists, and ground truth are public. Evaluation cases must not be used for fitting, hyperparameter selection, or preprocessing statistics. Contributors will calculate the metrics and extract the profiles from their own predictions. No surface meshes or volume fields are submitted. Use the BlendedNet benchmark specification for the exact split, metric, case, panel, station, and quantity IDs. The reference equations and code define how the scalar values must be calculated, and the worked examples show the JSON structure.

Before opening a pull request, run python scripts/validate_submission.py --contributor-stage submissions/blendednet/<submission-id>. The validator checks the schema, split identity, derived-score arithmetic, profile coverage, array lengths, ordering, finite values, and chunk hashes. It checks the submitted package's internal consistency; it does not run the contributor's model or recalculate base metrics from full fields.

A passing validator or pull request will not make a result official. Official results will require openly accessible evaluation code pinned to an immutable revision, an openly accessible versioned model artifact with a cryptographic digest and licence, a locked environment, artifact documentation, and maintainer approval of the validated submission package. The public validation record states that its scope is submitted data only: FluidsBench does not execute the contributor's code or model or recompute base metrics.

Prototype notice: current case IDs, ground truth, profile values, and leaderboard rows are illustrative dummy data. Dataset owners must replace and approve these materials before submissions open; none of the current rows is an official or approved result.

Leaderboard metrics

FluidsBench ranks blended_surface_rel_l2, the mean relative L2 error across Cp, Cfx, and Cfz. Lower is better. This aggregate is a FluidsBench display rule; the paper reports the component metrics separately.

MSE = (1/N) sum_i (yhat_i-y_i)^2

MAE = (1/N) sum_i |yhat_i-y_i|

L1_rel(%) = 100 sum_i |yhat_i-y_i| / sum_i |y_i|

L2_rel(%) = 100 sqrt(sum_i (yhat_i-y_i)^2) / sqrt(sum_i y_i^2)

R2 = 1 - sum_i (y_i-yhat_i)^2 / sum_i (y_i-mean(y))^2

surface_mean_L2 = (L2_Cp + L2_Cfx + L2_Cfz) / 3

Profile comparisons

BlendedNet publishes surface coefficient fields rather than full three-dimensional flow fields. The leaderboard therefore shows pressure and skin-friction cuts, but does not invent a velocity-profile comparison.

Current ground-truth and submitted curves are clearly labelled illustrative dummy data. They must be replaced once FluidsBench publishes a canonical case, extraction coordinates, interpolation rule, and tolerance for each cut.
