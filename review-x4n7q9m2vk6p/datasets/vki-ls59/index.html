VKI-LS59 dataset

Dataset overview and leaderboard submission format for VKI-LS59.

Overview

VKI-LS59 contains 839 two-dimensional CFD simulations of the LS59 turbine cascade across inlet incidence and outlet Mach number. FluidsBench follows the PLAID release: 671 cases form the published training pool and 168 cases form the published evaluation set. Under the FluidsBench open-reproducibility policy, the scored case list and ground truth are public.

The model inputs are angle_in, mach_out, geometry, and signed-distance information. Stored outputs are density (ro), momentum (rou and rov), energy (roe), turbulent kinematic viscosity (nut), Mach number (mach), and blade-surface isentropic Mach number (M_iso). Scalar targets are the source dataset's unexpanded Q quantity, power, pressure ratio (Pr), temperature ratio (Tr), isentropic efficiency (eth_is), and outlet angle (angle_out).

Planned open-reproducibility submission

Submissions are currently closed. When they open, contributors will propose one result directory at submissions/vki-ls59/<submission-id>/ in the FluidsBench submission repository. The planned result package contains:

  • submission.json for model metadata and the required scalar metrics;
  • evaluation-evidence.json linking those submitter-provided metrics to the declared evaluation revision and profile-index checksum;
  • profiles/index.json listing the lightweight profile chunks; and
  • profiles/chunk-*.json containing profile coordinates and predictions for the declared test cases.

FluidsBench uses an open reproducibility track. The declared evaluation partition, scored case lists, and ground truth are public. Evaluation cases must not be used for fitting, hyperparameter selection, or preprocessing statistics. Contributors will calculate the metrics and extract the profiles from their own predictions. No surface meshes or volume fields are submitted. Use the VKI-LS59 benchmark specification for the exact split, metric, case, panel, station, and quantity IDs. The reference equations and code define how the scalar values must be calculated, and the worked examples show the JSON structure.

Before opening a pull request, run python scripts/validate_submission.py --contributor-stage submissions/vki-ls59/<submission-id>. The validator checks the schema, split identity, derived-score arithmetic, profile coverage, array lengths, ordering, finite values, and chunk hashes. It checks the submitted package's internal consistency; it does not run the contributor's model or recalculate base metrics from full fields.

A passing validator or pull request will not make a result official. Official results will require openly accessible evaluation code pinned to an immutable revision, an openly accessible versioned model artifact with a cryptographic digest and licence, a locked environment, artifact documentation, and maintainer approval of the validated submission package. The public validation record states that its scope is submitted data only: FluidsBench does not execute the contributor's code or model or recompute base metrics.

Prototype notice: current case IDs, ground truth, profile values, and leaderboard rows are illustrative dummy data. Dataset owners must replace and approve these materials before submissions open; none of the current rows is an official or approved result.

Leaderboard metrics

The primary ranking is total_error, the arithmetic mean of the official PLAID RRMSE values for mach, nut, and the six scalar outputs. Lower is better. FluidsBench also displays relative L1, relative L2, and R2 for each ranked output.

RRMSE_field = sqrt((1/n) sum_i [((1/N_i) ||fhat_i - f_i||_2^2) / ||f_i||_inf^2])

RRMSE_scalar = sqrt((1/n) sum_i [|shat_i - s_i|^2 / |s_i|^2])

total_error = (1/m) sum_j RRMSE_j

L1_rel(%) = 100 sum_i w_i |yhat_i-y_i| / sum_i w_i |y_i|

L2_rel(%) = 100 sqrt(sum_i w_i (yhat_i-y_i)^2) / sqrt(sum_i w_i y_i^2)

R2 = 1 - sum_i (y_i-yhat_i)^2 / sum_i (y_i-mean(y))^2

Dimensional MAE/RMSE columns are intentionally not enabled until FluidsBench fixes a canonical public denormalization and unit convention for every VKI-LS59 output.

Profile comparisons

The planned submitter-provided profile format uses the following station IDs and quantities:

  • pressure_side and suction_side: M_iso against normalized chord.
  • outlet_plane_2: normalized downstream velocity against pitch fraction.

The current curves are clearly labelled prototype data for interface testing. The outlet trace is associated with the published LS59 downstream plane at x/c = 2.842; it is not presented as an experimental trace.
