AirfRANS dataset

Dataset overview and leaderboard submission format for AirfRANS.

Dataset specification

AirfRANS is a high-fidelity CFD dataset for two-dimensional incompressible steady-state Reynolds-Averaged Navier-Stokes solutions around airfoils. It targets surrogate models that predict flow fields and aerodynamic coefficients over NACA 4- and 5-digit airfoils.

The dataset is described in the AirfRANS paper. Code and loading utilities are available from the AirfRANS benchmark repository and airfrans_lib.

Dataset summary

Geometry
NACA 4- and 5-digit airfoils.
Cases
1,000 two-dimensional RANS simulations.
Flow regime
Subsonic, steady-state, incompressible RANS.
Conditions
Reynolds numbers between 2 million and 6 million, with angles of attack between -5 and 15 degrees.
Benchmark splits
Full, Scarce, Reynolds extrapolation, and AoA extrapolation.
Fields
Velocity components, reduced pressure, turbulent kinematic viscosity, and surface pressure coefficients.

Open-reproducibility submission

Check this dataset's current submission status on the leaderboard before preparing a result. Contributions are accepted only while its exact scoring-support release is owner-approved, marked official, and open. For an open dataset, contributors propose one result directory at submissions/airfrans/<submission-id>/ in the FluidsBench submission repository. The planned result package contains:

  • submission.json for model metadata and the required scalar metrics;
  • evaluation-evidence.json linking those submitter-provided metrics to the declared evaluation revision and profile-index checksum;
  • discretization.json describing the training input and supervision supports, inference input, direct model outputs, and mapping to the official scoring support;
  • discretization/cases.jsonl recording case-level counts, domains, mapping, and declared scoring coverage;
  • metrics/cases.json recording the official-support errors and coverage for every declared evaluation case;
  • profiles/index.json listing the lightweight profile chunks; and
  • profiles/chunk-*.json containing profile coordinates and predictions for the declared test cases.

FluidsBench uses an open reproducibility track. The declared evaluation partition, scored case lists, and ground truth are public. Evaluation cases must not be used for fitting, hyperparameter selection, or preprocessing statistics. Contributors will calculate the metrics and extract the profiles from their own predictions. Each dataset specification fixes the locations, IDs, weights, targets, and coverage used for final scoring. A model may infer on a different point set, mesh, or grid, but its predictions must be mapped onto that official support before the reference evaluator calculates the errors. Leaderboard field errors are calculated on the declared evaluation/test cases, not on the training cases. Full meshes and volume fields are not committed to the submission repository. Contributors may optionally publish example cases or the complete scored predictions in a public, immutable external repository and link that artifact from the submission. Use the AirfRANS benchmark specification for the exact split, metric, case, panel, station, and quantity IDs. The reference equations and code define how the scalar values must be calculated, and the worked examples show the JSON structure.

Before opening a pull request, run python scripts/validate_submission.py --contributor-stage submissions/airfrans/<submission-id>. The validator checks the schema, split identity, scoring-support binding, derived-score arithmetic, profile coverage, reported discretization, array lengths, ordering, finite values, and file hashes. It checks the submitted package's internal consistency; it does not run the contributor's model or recalculate base metrics from full fields.

A passing validator or pull request will not make a result official. Official results require maintainer approval of the validated submission package. Public code, model, and environment artifacts and their documentation are optional. If supplied, they must use stable links and include the revisions, digests, and licences required by the submission schema; the leaderboard reports those details. Their absence does not change accuracy rank, citation eligibility, or promotion eligibility. Prediction sharing is also optional. When prediction artifacts are shared, the leaderboard separately reports their coverage, artifact-check status, and whether any metrics were recomputed; it does not collapse those distinct checks into a generic “verified” badge. The public validation record states exactly what FluidsBench checked.

Prototype notice: any case IDs, ground truth, profile values, or leaderboard rows labelled prototype are illustrative dummy data. Dataset owners must replace and approve those materials before their dataset opens; a prototype row is never an official or approved result.

Metric definitions

Relative L2 error
For a target field q, first map predictions and targets back to dimensional physical space: q* = inverse_transform(q). The score is ||q_pred* - q_true*||_2 / ||q_true*||_2, reported as a percentage.
Relative L1 error
After the same dimensional inverse transform, the score is ||q_pred* - q_true*||_1 / ||q_true*||_1, reported as a percentage.
Dimensional evaluation
AirfRANS models are commonly trained on normalized fields. FluidsBench relative L1/L2 metrics should be computed after undoing those normalizations, not on the normalized fields reported by the original MSE tables.
Surface pressure relative L1/L2
Relative L1 and L2 error for dimensional pressure on the airfoil surface.
Surface wall-shear relative L1/L2
Relative L1 and L2 error for the two-dimensional wall-shear vector on the airfoil surface.
Volume velocity and pressure relative L1/L2
Velocity uses the flattened u_x and u_y components across all evaluated cases and mesh points. Pressure uses the flattened volume pressure values.
Cd and Cl R2
R2 over all evaluated cases using drag and lift coefficients computed from the predicted fields. The original AirfRANS paper reports force relative errors and Spearman correlations; FluidsBench should compute R2 directly when evaluator outputs are available.
Cp cut R2
One global R2 over all selected airfoil surface pressure coefficient samples from held-out cases, flattened across case_id, cut_id, station_id, and chordwise sample locations.
Velocity profile R2
R2 over selected boundary-layer velocity profiles, flattened across stations, cases, sample points, and velocity components.

Prototype values

The current leaderboard rows use the full-data-regime AirfRANS baseline tables from arXiv v3. The paper reports normalized-field MSE, force relative errors, Spearman correlations, and parameter counts. Because those are not the final FluidsBench dimensional relative L1/L2 and R2 evaluator outputs, the displayed field and force scores are prototype conversions and should be replaced by official evaluator exports.
